Command Guide

🖱️ Mouse Tracking Commands

Action Gesture
System ON / OFF Close BOTH eyes for 1.2 seconds
Move Cursor Move your nose slightly (High Sensitivity)
Left Click Wink Left Eye
Double Click Wink Left Eye twice quickly
Right Click Wink Right Eye
Drag / Select Text Wink and HOLD Left Eye for 0.5s
Scroll Up/Down Open Mouth + Look Up/Down

🎙️ Voice Keyboard Commands

Voice Command Action Executed
"Keyboard On" Activates Voice Control (Disables mouth scroll)
"Keyboard Off" Deactivates Voice Control
"Scroll Down" / "Page Down" Scrolls half a page down
"Scroll Up" / "Page Up" Scrolls half a page up
"Delete" / "Delete Word" Deletes the last complete word
"Backspace" Deletes a single letter
"Enter" / "New Line" Presses the Enter key
"Select All" / "Copy" / "Paste" Performs standard shortcuts (Ctrl+A/C/V)
(Anything else) Types the dictated sentence normally
